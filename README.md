# nvim

Hand-written Neovim configuration. No distribution: every plugin, option and
keymap is declared in this repo and commented in place.

## Layout

    init.lua                 requires the four config modules, in order
    lua/config/options.lua   editor options
    lua/config/keymaps.lua   global keymaps (plugin keymaps live with their plugin)
    lua/config/autocmds.lua  event hooks
    lua/config/plugins.lua   the plugin list (vim.pack.add) and which modules to load
    lua/plugins/<name>.lua   one module per plugin or topic, calls its setup()
    lsp/<server>.lua         one language-server definition per file (vim.lsp.config)
    nvim-pack-lock.json      pinned plugin revisions, generated by vim.pack

Design notes and the build log are in `.plans/`.

## How it installs itself

- Plugins: `vim.pack` (built into Neovim 0.12) clones anything missing on
  first launch and pins revisions in the lockfile.
- Tools: `mason.nvim` installs language servers, formatters, linters and the
  tree-sitter CLI listed in `lua/plugins/mason.lua`. Mason is a downloader
  only; it never installs runtimes.
- Parsers: `lua/plugins/treesitter.lua` compiles missing tree-sitter parsers.

First launch takes a few minutes; watch `:Mason`. Do not quit while installs
run.

## Prerequisites

Runtimes the tools build on, installed by the dotfiles setup:

    neovim >= 0.12, git, a C compiler, node, go, ripgrep
    uv, then `uv python install 3.12 --default` (Mason's pip packages need a
    python with ensurepip; Ubuntu's system python ships without it)
    rustup (only for Rust projects)

Dependencies, the Nerd Font, and the shell / tmux / Ghostty configuration this
setup assumes live in the dotfiles repo, which includes this one as a
submodule and installs everything in one step:

    git clone --recurse-submodules https://github.com/kilupskalvis/dotfiles ~/dotfiles
    ~/dotfiles/setup.sh
